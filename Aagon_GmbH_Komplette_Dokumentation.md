## 3. KERNPRODUKTE UND -LÖSUNGEN

### 3.1 ACMP (Aagon Client Management Platform)

**Überblick:**
- Modulare Client-Management-Lösung
- "Software Made in Germany"
- On-Premise-Lösung mit Cloud-Integration
- Unified Endpoint Management (UEM)
- Aktuelle Version: 6.8.x (Stand: 2025)

**Architektur:**
- Zentrale ACMP Client Management Database
- ACMP Console (zentrale Verwaltungsoberfläche)
- ACMP Gateway
- Report Engine
- Verteilte File Repositories
- ACMP Agents (auf Clients/Servern)

**Modularer Aufbau:**
ACMP besteht aus verzahnten Modulen, die einzeln lizenziert werden können:

#### 3.1.1 ACMP Core (Basis)

**Enthaltene Komponenten:**
- ACMP Inventory (Inventarisierung)
- ACMP Gateway
- ACMP Console
- Report Engine
- Kiosk (Self-Service)
- Verteilte File Repositories
- Vertrags- und Dokumentenmanagement
- Benutzerverwaltung
- Server-Komponenten

#### 3.1.2 Inventory & Asset Management

**ACMP Inventory:**
- Vollständige Hardware- und Software-Inventarisierung
- Automatische Erfassung aller Endgeräte
- Detaillierte Systeminformationen

**ACMP Asset Management:**
- Verwaltung von Anlage- und Materialvermögen
- Flexible Zuordnung von Standort, Eigentümer, Status
- Logische Gruppierung von Assets

**ACMP License Management:**
- Erfassung von Lizenzverträgen inkl. Lieferanten- und Kontaktdaten
- Kündigungs- und Verlängerungsfristen-Management
- Erkennung von Unter- und Überlizenzierung
- Automatische Compliance-Berechnung
- Unterstützung komplexer Lizenzmetriken (CPUs, Cores, Virtualisierung)
- Anpassbare Reporting-Optionen
- ROI-Optimierung durch Kostenreduzierung

#### 3.1.3 Software Distribution & Deployment

**ACMP Managed Software:**
- Automatische Softwareverteilung
- Vorgefertigte Software-Bundles für Drittsoftware
- Zentrale Paketverteilung über "Package Cloud"
- Zeitgesteuerte Installation
- Automatisierung des gesamten Softwareverteilungsprozesses

**ACMP Desktop Automation (Client Commands):**
- Technologisches Herzstück von ACMP
- Script-basierte Automatisierung (PowerShell, Bash, zsh)
- Keine umfangreichen Programmierkenntnisse erforderlich
- Verwaltung administrativer Aufgaben auf Server- und Client-Systemen
- Unterstützung für Windows, Linux (Bash), macOS (zsh)

**ACMP OS Deployment (OSD):**
- Netzwerkbasierte Betriebssysteminstallation
- Volle UEFI- und Secure Boot-Unterstützung
- Driver Scanner für automatische Treiberverteilung
- Boot Images, Response Files
- Rollout-Templates für automatisierte Installation
- Post-Deployment-Jobs (Software, Konfigurationen, Zertifikate)

#### 3.1.4 Patch Management

**ACMP Complete Aagon Windows Update Management (CAWUM):**
- Automatisiertes Windows-Patch-Management
- **Tägliche Updates** (im Gegensatz zu WSUS mit monatlichen Updates)
- Zentrale Verwaltung über Package Cloud
- Zeitgesteuerte Installation
- Reduzierung von Sicherheitslücken

**Drittanbieter-Patch-Management:**
- Integriert in ACMP Managed Software
- Vorgefertigte Pakete für gängige Drittanbietersoftware
- Automatische Update-Verteilung

#### 3.1.5 Security Management

**ACMP Security Detective (Virenschutzkontrolle):**
- Zentrale Erfassung von Sicherheitsinformationen
- Bisher nur lokal verfügbare Sicherheitsdaten werden zentralisiert
- Analyse über Reports und Abfragen in Client Management Database
- Einfach strukturierte Queries

**ACMP Vulnerability Management:**
- Integration mit CVS/CVE-Datenbank
- Identifizierung kritischer Sicherheitslücken
- Detaillierte Übersicht über potenzielle Schwachstellen
- Dateipfad-Anzeige für Vulnerabilities (ab Version 6.8.0)
- Frühzeitige Maßnahmeneinleitung

**ACMP BitLocker Management:**
- Zentrale Verwaltung von Betriebssystem- und Festplattenverschlüsselung
- Basiert auf Microsoft BitLocker
- Zusätzliche praktische Funktionen
- Schutz vor externen Bedrohungen
- BSI-Compliance-Unterstützung

**ACMP Defender Management:**
- Integration in Security-Module
- Zentrale Verwaltung von Microsoft Defender

#### 3.1.6 IT Service Management

**ACMP Helpdesk:**
- Ticket-Management-System
- Integriertes Zeit- und Kostenmanagement
- SLA-konforme Bearbeitung
- Knowledge-Base-Integration
- Eskalationsmanagement mit konfigurierbaren Regeln
- E-Mail-Integration
- CTI (Computer Telephony Integration)
- Zugriff auf inventarisierte Hardware-/Softwarewerte

**Zugriffsmöglichkeiten:**
- ACMP Console (Desktop-Anwendung)
- Web-Interface (Helpdesk Staff)
- Self-Service-Portal (End-User)
- ACMP App (Mobile Ticketbearbeitung)

**Remote Maintenance (Fernwartung):**
- Integrierte Fernwartungssoftware
- Direkte Verbindung zu Endgeräten
- Hohe Geschwindigkeit auch über schmalbandige WAN-Verbindungen
- Nahtlose Integration in Helpdesk

#### 3.1.7 Cloud & Hybrid Management

**ACMP Intune Management:**
- **Zentrale Integration von Microsoft Intune in ACMP Console**
- Multi-Tenancy-Fähigkeit (beliebig viele Intune-Tenants)
- Gemeinsame Verwaltung von Cloud- und On-Premises-Geräten
- Import mobiler Gerätedaten aus Microsoft Intune Cloud
- Gerätekonfiguration, -reset und -sperrung über ACMP Console
- Ergänzung von Intune mit ACMP-Funktionen:
  - Lizenz- und Vertragsmanagement
  - Asset Maintenance
  - Server-Management

**Hybrid UEM Strategy:**
- Kombination von Cloud (Intune) und On-Premises (ACMP)
- Einheitliche Verwaltungsoberfläche
- Keine wiederholten Logins beim Tenant-Wechsel

**Azure Cloud Deployment (NEU ab ACMP 6.8.0 - Mai 2025):**
- **Azure SQL Database Unterstützung** neben Microsoft SQL Server
- **Vollständiger Azure-Betrieb möglich** - ACMP Server kann komplett in Azure-Umgebung betrieben werden
- **Microsoft Azure Marketplace:** ACMP als SaaS-Angebot verfügbar
- **Cloud-Native Option:** Alternative zum traditionellen On-Premises-Deployment
- **Hybrid-Flexibilität:** Wahl zwischen On-Prem, Azure oder Hybrid-Deployment

**Aktuelle Version:**
- ACMP 6.8.3 (September 2025) - neueste Release
- ACMP 6.8.2 (August 2025)
- ACMP 6.8.0 (Mai 2025) - Azure SQL Support eingeführt
